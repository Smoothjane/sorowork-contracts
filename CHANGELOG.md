# Changelog

All notable changes to the SoroWork contracts will be documented in this file.

## [0.1.0] - 2026-11-26

### Added
- BountyEscrow contract with full lifecycle (create, assign, submit, approve, refund)
- CommunityTreasury contract with admin-controlled distributions
- ContributionRegistry contract for on-chain work records
- Unit tests for all three contracts
- GitHub Actions CI workflow
- Testnet deployment documentation
